# GoHook docs

The public docs for GoHook. They live at docs.gohook.dev.

- React and Vite, in the GoHook dark style.
- Each page is a markdown file in `src/content`. The group and order are set in `src/pages.ts`.
- Push to `main`, and GitHub Pages publishes it.

```bash
npm install
npm run dev
npm run build
```

Nothing from the paid handbook goes in this repo.
