# Ask

**The problem:** finding out what people really think of you takes hours of scrolling.

**What Ask does:** you ask a question. You get a short answer built from real Reddit threads. Every source is linked.

## How to use it

1. Type a product name or a question. For example, "Notion vs Obsidian".
2. Read the results. They split into pricing, complaints, comparisons, praise and quotes.
3. Open any source. Read the full thread.
4. Save the ones that matter to the Board.

## What to know

Ask reads public Reddit threads. If few people talked about it, you will see few results. We will not pad it.
