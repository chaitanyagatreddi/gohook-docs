# Graph

**The problem:** it is hard to see the big picture across everything you have found.

**What Graph does:** a map of the threads, subreddits and topics you searched or saved. The most connected ones sit on top.

## How to use it

1. Search and save threads like you normally do.
2. Open Graph to see how they connect.
3. Use the search box to find anything on the map.
4. Start with the communities that matter most to you.
